# 2026-11-19 작업 기록

- 날짜: 2026-11-19

## 목표

목업을 `mock/index.html` 하나로 줄인다. `groups.html`, 애니메이션 목업, 그룹 전용 검사·테스트를 제거한다. 서브에이전트 호출 시각화를 없애고, 각 워크트리의 세션별로 최근 호출한 도구 1개를 보드와 inspector에 표시한다. 채팅에서는 사용자와 에이전트를 시각적으로 구분하고, 에이전트 턴에 접이식 블록으로 생각과 도구 사용을 보여준다. 진행 중에는 `Thinking...`, 답변이 나온 뒤에는 `Thought for Ns`로 표시한다.
