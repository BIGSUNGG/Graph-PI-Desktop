# 2026-11-26

## 보드 배경 그라디언트 (사용자가 4개 항목 직접 선택)

요청: "가장 비주얼 적으로 좋은 방법을 찾아서 배경 이미지를 어떻게 적용할지 정하고 작업하자".

`ask_user_question` 으로 네 가지를 확정했다. ① 소재 = CSS 그라디언트(이미지 에셋 없음) ② 범위 = 보드 캔버스 영역만 ③ 가독성 = 딤 오버레이 + 카드 불투명 ④ 제어 = 설정 토글. 설계 승인 후 구현했다. 결정과 대안은 [[ADR-0010-board-background-gradient]] 에 남겼다.

변경:

- `src/shared/contract/app.ts` — `Settings.background: boolean`, `DEFAULT_SETTINGS.background = true`.
- `src/main/state/store.ts` — `sanitizeSettings` 가 boolean 이 아닌 값은 기본값으로 되돌린다.
- `src/renderer/src/state/app-store.tsx` — `AppActions.setBackground(on)` 추가(기존 `app:settings:set` 부분 갱신 재사용).
- `src/renderer/src/App.tsx` — `BoardView` 가 `.graph-wrap` + `has-bg` 를 조건부로 그린다.
- `src/renderer/src/styles/mock.css` — `.graph-wrap.has-bg`(radial 2장 + 세로 딤 + `--bg`), `.graph-wrap.has-bg .board-session-card{fill:var(--card)}`, `.tb-bg` 토글 버튼.
- `src/renderer/src/shell/RailHeader.tsx` — 타이틀바 우상단 `배경` 토글(`aria-pressed`, `.titlebar button` 은 이미 `no-drag`).
- `e2e/background.spec.ts` — 신규 1건.

관찰: 보드 캔버스에만 좌상단 파랑·우하단 보라 글로우가 깔리고, 사이드바·인스펙터·타이틀바는 불투명 다크를 유지한다. 노드 카드는 `fill=rgb(23,23,23)` 로 불투명해 텍스트 대비가 유지된다.

남은 것: 배경 이미지로 바꾸고 싶다면 계약(`Settings.background`)과 클래스 지점(`.graph-wrap.has-bg`)을 그대로 두고 CSS 레이어만 교체하면 된다. 파일 선택 UI 는 이번 범위가 아니다.
