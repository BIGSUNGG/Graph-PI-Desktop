## 남은 문제·미검증

- 목업은 사용자 확인 전이다. 확인 후 명세(`docs/30-specs/SPEC-graph-pi-ade.md`) 갱신과 구현을 시작한다.
- 활성 goal의 검증 계약이 이전 수직 슬라이스(앱 구현) 계약으로 남아 새 목업 데이터 objective와 충돌한다. 완료 주장 전에 사용자 확인을 받아 계약을 교체해야 한다.
- `orca agent launch --agent pi`의 실제 세션 생성은 여전히 미검증이다.
- 목업에서 확정할 미정: 그룹 생성 진입 위치, Loop 부모 자동 지정 여부, 그룹 이름 중복·정렬, 자식 브랜치 기본값, 삭제된 워크트리 세션의 히스토리 표시, 허브 재시작, 허브 최대 1개 확인.
- LSP 스타일 권고 3건(`indexOf`→`includes` 등)은 동작에 영향이 없어 수정하지 않았다.
