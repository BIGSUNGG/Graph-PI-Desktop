# 2026-11-18 작업 기록

- 날짜: 2026-11-18

## 목표

그룹 프리셋(Feature·Loop·Manual) 기획을 확정하고, 구현 전에 사용자가 직접 열어 확인할 수 있는 목업 6화면을 만든다. 이어서 두 목업(`index.html`, `groups.html`)이 하나의 가상 프로젝트 더미 데이터를 공유하도록 통합하고, 그룹·워크트리·세션·Loop·Orca 동작을 팝업으로 추가해 실제 데이터가 바뀌게 한다. 마지막으로 `index.html`의 그룹 생성·그룹 삭제·Orca 불일치·워크트리 추가 팝업을 `groups.html` 디자인으로 통일한다. Loop 설정은 세션을 선택했을 때 우측 inspector 하단 섹션으로 옮기고, 이미 켜진 Loop만 설정할 수 있게 한다.

## 남은 문제·미검증

- 목업은 사용자 확인 전이다. 확인 후 명세(`docs/30-specs/SPEC-graph-pi-ade.md`) 갱신과 구현을 시작한다.
- 팝업 작업과 index 디자인 정렬은 아직 커밋하지 않았다. 사용자 확인 후 커밋 여부를 정한다.
- Loop 켜기 UI는 목업에 없다. 실제 앱에서는 세션에서 명령으로 켜는 전제이므로, 목업은 이미 켜진 Loop만 보여준다.
- `mock/index.html`에 `deleteDialog`·`renameDialog`·`_oldWorktreeDialog`·`loopDialog`가 정의만 남아 있다. 동작에 영향은 없지만 다음 정리 때 제거한다.
- 팝업 구현으로 그룹 생성 진입(사이드바 `+`/보드 헤더), Loop 부모(첫 워크트리/부모 변경), 이름 중복 인라인 오류, 브랜치 기본값 `feature/<이름>`, 삭제 세션 히스토리(소프트 삭제+`삭제됨`), 허브 지정/해제를 확정했다. 허브 재시작만 미검증이다.
- `orca agent launch --agent pi`의 실제 세션 생성은 여전히 미검증이다.
- LSP 스타일 권고 3건(`indexOf`→`includes` 등)은 동작에 영향이 없어 수정하지 않았다.
