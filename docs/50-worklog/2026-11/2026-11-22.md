# 2026-11-22 작업 기록

- 날짜: 2026-11-22

## Audit 구조 재정의와 상태·오류 화면 제거

### 목표

목업에서 상태·오류 전용 화면과 독립 Audit 세션 카드를 제거한다. Audit을 세션 Audit과 그룹 Audit으로 나누고, 그룹 Audit은 모든 세션 Audit이 승인된 뒤에만 시작하며, 감사 에이전트가 생략할 수 있게 한다.

### 확정한 결정

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| Audit 종류 | 세션 Audit과 그룹 Audit | 세션은 자기 작업만, 그룹은 모든 세션 결과를 통합 검사한다 |
| 세션 Audit 위치 | 해당 세션 인스펙터의 Audit 탭 | 작업 범위를 그 세션으로 한정한다 |
| 그룹 Audit 위치 | 허브 인스펙터의 Audit 탭 | 그룹 전체 결과를 한 곳에서 판정한다 |
| 그룹 Audit 시작 조건 | 모든 하위 세션 Audit이 `approved` | 미승인 세션이 있으면 통합 판정을 시작하지 않는다 |
| 그룹 Audit 생략 | 감사 에이전트가 판단하며, 생략 시 그룹 Goal `complete` | 통합 감사가 불필요한 경우에도 완료를 막지 않는다 |
| 생략 표시 | `통합 감사 생략` 카드에 사유·시각·판단 주체 | verdict와 생략을 구분한다 |
| 보드 표시 | 독립 Audit 카드·노드 없음 | Audit은 세션/허브 Audit 탭과 이력에만 둔다 |
| 상태·오류 화면 | 화면·데이터·검증·증거 모두 제거 | 사용자가 전용 창을 원하지 않았다 |
| 예시 그룹 | `g-feature`를 완료 예시로 사용 | 모든 세션 승인 후 그룹 Audit 생략 장면을 보여준다 |
