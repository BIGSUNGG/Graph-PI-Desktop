## Audit 구조 재정의와 상위 세션 Audit

### 목표

목업에서 상태·오류 전용 화면과 독립 Audit 세션 카드를 제거한다. Audit을 세션 Audit·상위 세션 Audit·그룹 Audit으로 나누고, 자식 Goal이 있는 세션과 그룹 Goal은 직계 자식 Goal의 Audit이 모두 승인·생략된 뒤 상위/그룹 Audit을 시작하며, 감사 에이전트가 생략할 수 있게 한다.

### 확정한 결정

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| Audit 종류 | 세션 Audit·상위 세션 Audit·그룹 Audit | 자식 없는 세션은 자기 작업만, 자식 있는 세션과 그룹은 자기 작업+직계 자식 결과를 통합 검사한다 |
| 세션 Audit 위치 | 해당 세션 인스펙터의 Audit 탭 | 작업 범위를 그 세션으로 한정한다 |
| 그룹 Audit 위치 | 허브 인스펙터의 Audit 탭 | 그룹 전체 결과를 한 곳에서 판정한다 |
| 그룹 Audit 대상 | 그룹 Goal이 만든 세션에서 진행된 Goal만 | 그룹이 만들지 않은 Goal은 통합 감사와 무관하다 |
| 그룹 Audit 없음 | 대상 Goal이 하나도 없으면 실행하지 않음 | 통합할 그룹 작업이 없는데 감사를 만들지 않는다 |
| 상위 세션 Audit 시작 조건 | 직계 자식 Goal이 모두 complete이고 최신 Audit이 `approved` 또는 `skipped` | 자식 Audit이 하위 계층을 정산하므로 부모는 직계 자식만 확인한다 |
| 그룹 Audit 시작 조건 | 그룹 Goal이 만든 세션의 직계 하위 Goal Audit이 모두 `approved` 또는 `skipped` | 상위 Audit 레코드를 별도 조건으로 나열하지 않고 직계 자식 settled만 확인한다 |
| 다단계 Goal | `parentGoalId`로 Goal→Goal→Goal 지원, 순환 금지 | 3단계 예시 `hub → web → qa`로 재귀를 확인한다 |
| 상위 Audit 라벨 | 비허브 상위 세션은 `상위 세션 Audit` | 허브의 `그룹 Audit`과 구분한다 |
| 상위 세션·그룹 Audit 생략 | 감사 에이전트가 판단하며, 생략 시 부모 Goal `complete` | 통합 감사가 불필요한 경우에도 완료를 막지 않는다 |
| 생략 표시 | `통합 감사 생략` 카드에 사유·시각·판단 주체 | verdict와 생략을 구분한다 |
| 보드 표시 | 독립 Audit 카드·노드 없음 | Audit은 세션/허브 Audit 탭과 이력에만 둔다 |
| 상태·오류 화면 | 화면·데이터·검증·증거 모두 제거 | 사용자가 전용 창을 원하지 않았다 |
| 예시 그룹 | `g-feature`를 완료 예시로 사용 | 그룹 생성 세션의 승인 후 그룹 Audit 생략 장면을 보여준다 |

- `pi` 는 유효한 에이전트 id이고 기본 설정에서 **터미널 표면**으로 뜼다. 채팅 표면(`--surface chat`)은 확인하지 않았다.
- **세션 JSONL 파일은 첫 턴 전에는 보이지 않았다.** 실행 08:37:14Z, 파일명 시각 08:37:17Z, 파일 mtime 08:37:51Z(첫 프롬프트 전송 이후). 즉 보드에 새 세션이 나타나는 시점은 첫 프롬프트 이후다.
- `terminal send` 는 `provider: unsupported` 로 전달을 관측하지 못한다. 앱은 전송 성공을 화면 출력이나 세션 파일 증가로 판정해야 한다(SPEC §3.5의 전송 중·전송됨 표시 근거).

## 보드 연결선 정리 — 워크트리 계층선 제거, 세션 방향 표시

### 목표

보드에서 워크트리 사이 부모·자식 회색 계층선을 없애고, 세션 연결선에 부모→자식 화살촉을 붙여 방향을 드러낸다. 워크트리 머지선은 유지한다.

### 확정한 결정

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 워크트리 계층선 | 허브→루트 트렁크와 열 버스·열 드롭을 모두 제거 | 사용자가 워크트리 간 부모·자식 연결선을 원하지 않았다 |
| 세션 방향 | 자식 노드 직전에 보라 화살촉(`marker-end`), 허브·교차 워크트리 선 포함 | 선 색·굵기만으로는 방향이 드러나지 않았다. 정적 표시라 `reduced motion`에서도 유지된다 |
| 머지선 | 주황 점선·화살촉·`merge` 라벨 유지 | 사용자가 유지 요청 |
| 범위 | 목업·검증·SPEC·worklog만, 데이터와 다른 화면 불변 | 승인 범위 |
