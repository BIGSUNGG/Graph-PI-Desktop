## 작성 규칙

- `_templates/worklog.md` 로 시작한다. 작업 단위마다 항상 남긴다.
- 실행한 명령과 그 결과를 적는다. 검증하지 않은 것은 "미검증"으로 표시하고 성공으로 쓰지 않는다.
